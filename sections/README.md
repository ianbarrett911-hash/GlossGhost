# GlossGhost Section Fragments

Reusable HTML fragments for the storefront.

## Suggested assembly order
1. `announcement.html`
2. `header.html`
3. `hero.html`
4. `feature-grid.html`
5. `ribbon.html`
6. `footer.html`
7. `cart-drawer.html`
8. `video-modal.html`

These fragments are intended to be composed by a future loader or build step. The live page currently remains in `GG4index.html` while the structure is being modularized.
